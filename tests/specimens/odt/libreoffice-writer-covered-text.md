# `libreoffice-writer-covered-text.odt`

**Producer:** LibreOffice 24.2 Writer. The same source as
[`docx/libreoffice-writer-covered-text.docx`](../docx/libreoffice-writer-covered-text.docx),
written by the same script into the other container.

## What the pair is for

Both formats state the same two things — a filled shape with an anchor and an
offset, and text with no position at all — and neither states that one is over
the other. The pair is here so the check that answers it is shown to work
against both families rather than against the one it was written on.

Unlike the slide pair, there is nothing to compare in how they *store* the
geometry, because neither of them stores it. That is the whole point of these
two files.

Everything in the text and the metadata is invented.
